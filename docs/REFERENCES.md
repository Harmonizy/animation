# References

Guidance in `docs/creative` is synthesized for this project. It is not an official rule of any studio
or author, and the works below are starting points rather than citations of specific claims.

**How these were checked.** Technical links and Sanderson's essay were found by web search during this
work, but not every page was read in full. The books are listed from general knowledge and were not
looked up or re-read for this project, so confirm the details before relying on them.
