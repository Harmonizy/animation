# Character design

**Status: guidance only (Planned).** There are no characters and no character schema in the code. Do
not create story characters until a later phase is authorized. Sources: [references](../REFERENCES.md).

## Psychology template

Psychological models describe people. They do not determine behavior, so use them to ask better
questions, not to generate rules.

| Field                   | Prompt                                                                                                         |
| ----------------------- | -------------------------------------------------------------------------------------------------------------- |
| Core personality        | How do they meet the world before thinking about it?                                                           |
| Big Five (optional)     | Continuous values for openness, conscientiousness, extraversion, agreeableness, neuroticism, never fixed types |
| Values and beliefs      | What do they protect, and what do they assume is true?                                                         |
| Want vs need            | What are they pursuing, and what would actually help?                                                          |
| Motivation and fear     | What pulls them forward, and what do they avoid at any cost?                                                   |
| Flaws and coping        | How do they protect themselves, and what does that cost?                                                       |
| Internal contradictions | Which two true things about them are in tension?                                                               |
| Relationships           | Who changes how they behave, and in what way?                                                                  |
| Arc                     | What changes by the end? Staying the same can also be a choice.                                                |

## Visual template

| Element           | Guidance                                                                                 |
| ----------------- | ---------------------------------------------------------------------------------------- |
| Shape language    | Associations such as round, square and angular are conventions that context can overturn |
| Silhouette        | Fill the figure solid black. If it cannot be recognized, redesign it                     |
| Visual hierarchy  | Decide what is read first, second and third, then support that order                     |
| Color palette     | Use a limited set with a defined role for each color, tested on likely backgrounds       |
| Costume and props | Should imply history and function, not only decoration                                   |

## Production sheets

- **Expression sheet:** range of emotion, including subtle states.
- **Pose sheet:** attitude through the whole body, with a clear line of action.
- **Turnaround:** consistent proportions across front, three-quarter, side and back views.
- **Acting notes:** how this particular person shows a feeling, which often differs from the obvious.

## Validation questions for future data

- Does every visual choice connect to something in the psychology template?
- Can the character be recognized in silhouette at phone size?
- Can they be told apart from every other character in the same frame?
