# Short-form storytelling

**Status:** multiple aspect ratios and safe areas are implemented. The rest is **guidance only**.
Sources: [references](../REFERENCES.md). The advice here is synthesized, not platform rules or data.

Attention serves the story, not the other way round. Do not trade quality or honesty for retention,
and do not promise something the film will not deliver.

| Tool                 | Purpose                                                          |
| -------------------- | ---------------------------------------------------------------- |
| Strong opening frame | A clear and intriguing image, readable even when paused          |
| Visual hook          | Motion or an image that raises interest without explanation      |
| Curiosity gap        | A real question the film will later answer                       |
| Immediate stakes     | Show quickly what could be lost                                  |
| Emotional hook       | Early reason to care about someone                               |
| Micro-payoffs        | Small answers along the way that reward continued watching       |
| Controlled pacing    | Vary rhythm: constant intensity flattens everything              |
| Final payoff         | An ending that resolves the opening promise                      |
| Loop-friendly ending | Optional, when last and first frames connect in a meaningful way |

## Mobile clarity

- Check at actual phone size, since silhouettes and small details can disappear.
- Keep key subjects inside the safe area. Platform UI can cover parts of the frame, and those areas
  vary, so check the current specification for each target platform.
- Use one clear idea per shot, and strong value contrast.
- Check that the film still works with the sound off, if that is a likely viewing mode.
